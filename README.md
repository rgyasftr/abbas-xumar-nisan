# Abbas & Xumar — Nişan Dəvətnaməsi 💍

Bu layihə [umud-laman-engagement.vercel.app](https://umud-laman-engagement.vercel.app/) saytının dizaynı əsasında **Abbas və Xumar** üçün fərdiləşdirilmiş nişan dəvətnaməsidir.

## 🌸 Məlumatlar
- **Cütlük**: Abbas & Xumar
- **Tarix**: 22 Noyabr 2026, Saat 18:00
- **Məkan**: Baharlı (Baharlı ailəvi istirahət kompleksi)
- **Xəritə keçidi**: [https://maps.app.goo.gl/W1vv5tdPuwHFhPU26](https://maps.app.goo.gl/W1vv5tdPuwHFhPU26)

## 🌸 Xüsusiyyətlər
- **İnteraktiv Zərf Açılışı**: Toxunduqda zərf açılır, fon musiqisi (Christina Perri - *A Thousand Years*) səslənir və əsas hissəyə keçir.
- **Dinamik Hero Hissəsi**: Arxa planda dövr edən video, zərif tipoqrafiya və dəvət başlığı.
- **Dəvətnamə Mətni & Çiçək Bəzəkləri**: Qızılı/terrakotta çalarları və SVG güllər.
- **Geri Sayım (Countdown)**: 22 Noyabr 2026, saat 18:00 tarixinə qədər gün, saat, dəqiqə və saniyə sayğacı.
- **Tədbir Proqramı**: Qonaqların qarşılanmasından DJ Party-ə qədər vaxt cədvəli.
- **Məkan & Xəritə**: Baharlı üçün interaktiv Google Xəritə və birbaşa naviqasiya düyməsi.
- **Canlı Təbrik Kitabı (Ürək Sözləri)**: Qonaqların ad və təbriklərini göndərməsi və dərhal ekranda görünməsi.
- **Musiqi İdarəetmə Düyməsi**: Yuxarı sağ küncdə musiqini dayandırmaq/işə salmaq üçün zərif düymə.

## 🚀 Necə İşə Salmaq Olar?

### Seçim 1: Birbaşa brauzerdə açmaq
`index.html` faylını iki dəfə klikləyərək istənilən brauzerdə (Chrome, Edge, Safari, Firefox) aça bilərsiniz.

### Seçim 2: Yerli server ilə (Tövsiyə olunur)
```bash
python -m http.server 3000
```
Brauzerdə açın: `http://localhost:3000`
